# Extending Vizy

When your template needs different output, assign a [Block Type template](docs:template-guides/block-type-templates) to structured content or use [Modify Nodes](docs:template-guides/modify-nodes) to customise a node’s HTML.

To add editing tools, start with [Extensibility](docs:developers/extending-vizy). It explains how a Craft module registers a node or mark, connects its JavaScript, and enables it on an Editor Config. The [custom mark guide](docs:guides/developers/creating-a-custom-mark-from-scratch) takes an abbreviation button through to saved content and frontend HTML.
