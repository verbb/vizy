Vizy brings rich text and structured Craft content into one visual editor. Authors can write naturally, add purpose-built blocks exactly where they belong, and leave developers in control of the rendered HTML.

Combine familiar formatting with structured Vizy blocks in the same editing surface. Each block can use existing Craft fields, UI elements and tabs, then render through a focused project-owned Twig template.

## Features

- **Familiar formatting:** Give authors the rich-text controls they expect, including headings, lists, links and images.
- **Structured blocks:** Place project-specific components between paragraphs without switching to a separate page builder.
- **Focused toolbars:** Tailor each field to the tools its content actually needs.
- **Craft field layouts:** Reuse existing fields and organise larger blocks with tabs and UI elements.
- **Practical block controls:** Move, collapse, enable and disable blocks while keeping the document together.
- **Lean content loading:** Fetch the field’s JSON in a single database call instead of loading every block as an element.
- **Familiar content queries:** Filter, sort, limit and search nodes much like querying Matrix blocks.
- **Modular templates:** Render each block through its own Twig partial.
- **Nested content:** Use Vizy fields inside blocks when the content model genuinely calls for another level.
- **GraphQL:** Query generated HTML or raw nodes for headless delivery.
- **Supporting open source:** Every Vizy licence contributes funding to Tiptap and ProseMirror.
